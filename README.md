# SEG_Instance_1-Stage_SOLOv2

**SOLOv2 - instance segmentation (1-Stage) - training and test evaluation**

Part of the *Physical AI Segmentation* reference series of the **Statera Working Group**:
one model per repository, the same data, protocol and metrics for every model - only the model differs.
The data are the FashionLetters36 images of the *Physical AI Object Detection* series (`OD_Image_*`) with masks,
so the results are directly comparable with the detection results.

## Model

- Paper: Wang, Zhang, Kong, Li & Shen, *SOLOv2: Dynamic and Fast Instance Segmentation*, NeurIPS 2020 (arXiv:2003.10152)
- Implementation source: WXinlong/SOLO (solov2_r50_fpn_8gpu_1x), reimplemented
- Parameters: 46.39 M (36 classes)

- ResNet-50 + FPN P2-P6 (torchvision resnet_fpn_backbone)
- Grids S = 40 / 36 / 24 / 16 / 12; kernel branch (E = 256) and category branch, 4 x conv 512 + GN each
- Unified mask feature at stride 4; mask = sigmoid(dynamic 1x1 kernel * feature); no box head (box = tight box of the mask)

Loss / assignment: Dice (x 3) on the positive grid cells + sigmoid focal loss on the categories

Differences from the original (common protocol):

- No ImageNet weights, common init, no mean / std, 608 input, Adam 1e-4 constant, common augmentation (flip + YOLO-paper augmentation) and post-processing (see [Unified] markers)
- Trainable BN + PreciseBN before every evaluation and the final save (BN statistics of micro batch 2 are unusable)
- Box NMS on the mask boxes (common post-processing) instead of Matrix NMS

## Data: FL36-Seg (synthetic, generated by step 1)

FashionLetters36 regenerated with the same seed plus masks: 36 classes = Fashion-MNIST (10) + EMNIST letters (26);
608 x 608 canvases with 3-10 non-overlapping objects of 32-160 px; 4,096 train / 1,024 test images, fixed seed -
every user generates the same dataset, and images and boxes are identical to FashionLetters36. A mask is the glyph
pixels brighter than 30, the same threshold that defines the boxes. Instance masks: SegmentationObject PNGs (value k = k-th XML object); boxes = tight boxes of the masks.

EMNIST is downloaded from NIST; if the download is refused, fetch `gzip.zip` in a browser from
https://www.nist.gov/itl/products-and-services/emnist-dataset and run
`python data_processing_fl36seg.py --emnist-zip <path>/gzip.zip`.

## Results

Test set: FL36-Seg test (1,024 images, 6,699 objects, 36 classes), after 30 epochs (3.1 h on an RTX 4070 Laptop GPU).

| | AP50 | AP75 | **AP50:95** | Recall (IoU 0.5) |
| --- | --- | --- | --- | --- |
| mask | 0.8942 | 0.8243 | **0.6993** | 0.958 |
| box | 0.8851 | 0.8693 | 0.7751 | 0.955 |

The comparison metric of the series is **mask AP50:95** (mean over IoU 0.50, 0.55, ..., 0.95): on FL36-Seg every correct box is also a correct mask at IoU 0.5, so AP50 saturates.
Semantic mIoU derived from the instances (score >= 0.5, incl. background): 0.7299. Inference: 14.4 images / s incl. post-processing and mask decoding.

Convergence (test AP50 every 5 epochs):

| Epoch | 5 | 10 | 15 | 20 | 25 | 30 |
| --- | --- | --- | --- | --- | --- | --- |
| mask AP50 | 0.607 | 0.772 | 0.832 | 0.866 | 0.880 | 0.894 |
| box AP50 | 0.505 | 0.718 | 0.780 | 0.848 | 0.855 | 0.885 |

Protocol: 30 epochs, Adam lr 1e-4 (constant), effective batch 8 (micro batch 2 x 4 accumulation), input 608, seed 777,
no pretraining; augmentation: horizontal flip + the basic YOLO-paper augmentation (random scale / translation 20 %,
HSV hue 0.1, saturation / exposure 1.5); test evaluation every 5 epochs.

## Reference variant: SOLOv2 + BCE mask loss

`detectors/solov2_bce/`, `train_seg_solov2_bce.py`, `evaluate_seg_solov2_bce.py`: the same model with the mask loss
dice x 3 + 1.0 x BCE-with-logits. It was added during development, when the dice-only mask branch collapsed to
"every pixel 0" in an earlier run whose data loader had dropped the 26 letter classes (a class-name case bug,
fixed before the results reported here). BCE on the logits keeps a gradient on the object pixels however negative
the logits become. On all 36 classes the official dice-only loss converges, so the official SOLOv2 above is the
result of this repository; the variant is kept as a reference.

| SOLOv2 + BCE | mask AP50 | mask AP75 | mask AP50:95 |
| --- | --- | --- | --- |
| FL36-Seg test, 30 epochs | 0.8907 | 0.8127 | 0.6907 |

Its weights are in the same Release (`seg_solov2_bce_fl36seg_e030.pth`): put them into
`runs/seg_solov2_bce/checkpoints/` or pass `--weights <file>` to `evaluate_seg_solov2_bce.py`.

## Usage

```bash
pip install -r requirements.txt
python data_processing_fl36seg.py           # downloads Fashion-MNIST + EMNIST, generates FL36-Seg
python train_seg_solov2.py               # training, then test evaluation (runs/seg_solov2/)
python evaluate_seg_solov2.py            # test evaluation of runs/seg_solov2/checkpoints/ (or --weights <file>)
```

Data are expected under `$PHYSICAL_AI_ROOT/datasets` (default `~/Physical_AI/datasets`).
Smoke test: `python train_seg_solov2.py --epochs 1 --max-train 8 --max-test 4`.

Trained weights: the GitHub Release of this repository contains `seg_solov2_fl36seg_e030.pth` (the run reported above).
Put it into `runs/seg_solov2/checkpoints/` or pass `--weights <file>` to the evaluation script.
Demo scripts using these weights will be added in a later release.
